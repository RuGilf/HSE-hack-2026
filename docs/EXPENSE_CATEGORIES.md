# Категории расходов и прозрачная панель iOS

27 октября 2026.

Финансы → Категории открывает список. «Добавить категорию» создаёт новую;
«Изменить» позволяет поменять название и цвет (палитра или `#RRGGBB`). Название
до 40 символов; одинаковые имена видимых категорий без учёта регистра отклоняются.
«Скрыть» убирает категорию из новых расходов; «Вернуть» восстанавливает её.
Хотя бы одна категория остаётся видимой. Постоянного удаления и переназначения
истории при скрытии нет. Изменённые подписи и цвета сразу видны в диаграмме,
транзакциях и chips; суммы и category IDs старых расходов сохраняются.

Постоянный ID новой категории — `custom:<UUID>`. Существующие восемь ID прежние.
Неизвестные ID из старых расходов тоже доступны для настройки. SQLite хранит
только пользовательские определения и переопределения defaults. Таблица
`expenseCategory(id, name, colorHex, archived)` добавлена миграцией `1.sqm`
со схемы 1 до 2, без изменения task/expense/healthSnapshot. Запись на IO,
реактивное чтение SQLDelight Flow; ошибки сохранения оставляют форму открытой.

На iOS прежний UIKit interop по умолчанию вырезал прямоугольник в Compose под
UITabBar. Теперь native view имеет прозрачный фон, включён `placedAsOverlay`,
а содержимое экрана рисуется и прокручивается под панелью. Хвосты списков и
плавающие действия учитывают отдельный нижний отступ. Android-панель остаётся
стандартной Material 3. См. [документацию overlay interop](https://kotlinlang.org/docs/multiplatform/whats-new-compose-110.html#overlay-placement-for-interop-views).

## Проверка

```sh
./gradlew :androidApp:build :shared:testAndroidHostTest :shared:iosSimulatorArm64Test
xcodebuild -project iosApp/Lifety.xcodeproj -scheme Lifety -configuration Debug \
  -sdk iphonesimulator -destination 'platform=iOS Simulator,name=Lifety-iOS-QA' build
```

Android debug/release/lint и Xcode simulator build успешны. **163 host tests
passed, 6 live LLM skips; 65 Kotlin iOS tests passed**. Добавлены 4 common tests
для переопределений, старых ID, имён/цветов и последней видимой категории, а
также 4 host tests: миграция со схемы 1, реактивность/сохранность после открытия
файла заново, восстановление после ошибки записи, защита от конкурирующих записей.

На отдельном iPhone 17 QA simulator / iOS 26.5 проверены: обновление прежней БД
с двумя расходами; создание «такси» янтарного цвета; переименование «Транспорт»
в «поездки» и лиловый цвет; скрытие без изменения сумм; отсутствие скрытой
категории в новой форме; восстановление настроек после завершения процесса
и запуска обновлённого приложения; возврат категории. Новая категория также
видна в форме расхода и списке после перезапуска.

У прозрачного native tab bar проверены Finance portrait/landscape, содержимое
под стеклом без прямоугольной отсечки, пять переходов, Plan FAB, Health и отступ
composer Assistant. Листы категорий/расхода располагаются поверх панели;
кнопка сохранения категории доступна при экранной клавиатуре. Native interop
overlay — experimental API текущей зафиксированной версии Compose.

Физические устройства, Android UI runtime, iPad в этой итерации, VoiceOver и
максимальный Dynamic Type не проверены. Тестовые записи существуют только
в QA simulator; начальные данные приложения не подменялись.
