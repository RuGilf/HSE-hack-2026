Здесь показана исходная тема Lifety. Её значения определены в
`shared/src/commonMain/kotlin/ru/lifety/core/ui/LifetyDesign.kt`.
`LifetyTheme.kt` назначает все роли Material 3, включая secondaryContainer и
surface containers: стандартный фиолетовый акцент не должен возвращаться.
Тема выбирается в настройках: светлые Lifety Light, Catppuccin Latte, Gruvbox Light;
тёмные Lifety, Tokyo Night, Catppuccin Mocha, Gruvbox Dark, Nord.
Локальные темы feature-экраны не создают. Источник палитр —
`core/appearance/LifetyPalette.kt`, Material-роли — `LifetyTheme.kt`.
Primary/secondary containers мягко тонированы: selected chips и tonal controls
не превращаются в большие неоновые плашки. Цвет content каждой роли соответствует её назначению.
Android system bars меняют яркость значков вместе с темой. Системный splash
использует исходный фон; launcher mark меняется отдельным действием в настройках.

Внутри функций используйте `MaterialTheme.colorScheme`, `shapes`, `typography`.
`LifetyColors` предназначен для общих компонентов/brand drawing; не копируйте HEX
в каждый feature. Не оборачивайте экран дополнительным MaterialTheme с default
цветами — корень уже предоставляет тему всем пяти разделам.

## Цвета категорий расходов

Общая Android/iOS палитра определена в `LifetyColors.ExpenseCategory`.
`feature/finance/FinanceCategoryStyle.kt` связывает её со стабильными category IDs:

| ID | Категория | Цвет |
| --- | --- | --- |
| `food` | Продукты и кафе | `#5CDF85` |
| `transport` | Транспорт | `#73B7FF` |
| `shopping` | Покупки | `#D5A1FF` |
| `bills` | Дом и счета | `#F6C76B` |
| `health` | Здоровье | `#FF9BA8` |
| `leisure` | Досуг | `#60D5D2` |
| `education` | Учёба | `#B6C5FF` |
| `other` / неизвестные ID | Другое / исходное название | `#A8B5AC` |

Один цвет используется в полосах диаграммы, маркерах строк трат и chips редактора,
включая предложение категории. Он не зависит от суммы, сортировки, периода или
валюты. Выбранная категория обозначена галочкой, границей и мягким оттенком фона;
названия и суммы остаются обычным читаемым текстом. Цвет не заменяет название.
Модель Expense и сохранённые category IDs не меняются. Через Финансы → Категории
названия и цвета можно переопределить, добавить категорию или скрыть её. Поле
HEX позволяет задать свой цвет. Выбранный chip сохраняет контрастную галочку
независимо от пользовательского цвета; тёмные маркеры имеют тонкую границу.
Определения сохраняются отдельно в SQLite (`expenseCategory`, schema v2).

## Размеры и типографика

`LifetySpacing`: Screen 16 dp, Section 24 dp, Content 16 dp, Item 12 dp, Small 8 dp.
Основное действие — минимум 48 dp; FAB — M3 56 dp с rounded-square shape.
Card — 16–20 dp, inputs — стандартные M3 4 dp, sheet — 28 dp сверху.
Область выбора дня календаря — 48 dp. Минимальные интерактивные размеры M3 не отключаются.

Типографика — стандартная `Typography()` Material 3, системный шрифт.
Top app bar использует titleLarge 22 sp; нижние подписи — labelMedium 12 sp.
Заголовок раздела показывается в одном месте: общей TopAppBar. Внутри экранов —
локальные заголовки групп, без второго hero и длинного вступления перед формой.
Масштабирование шрифта сохраняется; не уменьшать текст под фиксированный контейнер.

Не добавляйте сильный glow к каждому контейнеру. Мягкое свечение — характерная
деталь маскота, остальные поверхности спокойные. Primary Button — неоновый фон,
тёмный текст; вторичные действия — FilledTonalButton/TextButton.

- `app/PlanScreen.kt`: SingleChoiceSegmentedButtonRow «День / Календарь» с

- Фильтры — FilterChip или SingleChoiceSegmentedButtonRow.
- Добавление/редактирование задач и расходов — **ModalBottomSheet**; даты —
  DatePicker. TaskEditorRoute, PlannerNavigation и repository signatures сохранены.
- `core/ui/LifetyDateField.kt`: `LifetyDateField(label, value, onChange, modifier,
  enabled)`, value — ISO civil date, без смены текущей финансовой модели.
- Finance: диапазон дат и настройка notifications раскрываются по действию;

- Assistant: ключ/endpoint/модель в раскрывающемся блоке; разрешения и preview
  видимы отдельно. API-ключ не попадает в rememberSaveable. Точный JSON сохраняется
  в предпросмотре перед отправкой; автоматических запросов нет.
- Health: M3 segmented periods 7/30/всё время, Canvas-графики сна/шагов и список
  дней. Выбор дня касанием графика либо обычными кнопками. Нулевые значения и
  пропуски различаются; средние только по известным дням. Ручная форма с датой —
  ModalBottomSheet, IME Next/Done, сохранение черновика и Snackbar после записи.
  Импорт раскрывается отдельно; график проявляется за 240 ms без задержки данных.
- Настройки открываются шестерёнкой в верхней панели: карточки восьми тем с
  предпросмотром, отдельная смена иконки в цвет выбранной темы, локальные данные.
  Пункт финансов/банковских уведомлений удалён. Подробности — [APPEARANCE.md](APPEARANCE.md).
- `core/ui/LifetyIcon.kt`: общие vector symbols для нижней панели и действий.
- `core/ui/LifetyEmptyState.kt`: единый empty state с маскотом, текстом и
  необязательным рабочим CTA. Не подставляйте числовые данные из картинки.

## Маскот Lifety

Общий компонент находится в
`shared/src/commonMain/kotlin/ru/lifety/core/ui/LifetyMascot.kt`, пакет
`ru.lifety.core.ui`.

```kotlin
@Composable
fun LifetyMascot(
    modifier: Modifier = Modifier,
    emotion: LifetyEmotion = LifetyEmotion.Happy,
    animated: Boolean = true,
)
```

Состояния: `Happy`, `Calm`, `Focused`, `Celebrating`, `Sleepy`.
Рисунок — code-native Canvas: неоновое кольцо, улыбка и мягкое свечение;
изображение не зависит от растровых assets, Android/iOS используют один код.
Анимация — дыхание/плавание на 3 dp, по 2,6 с в каждом направлении, без вспышек.
`animated=false` — статичная версия для маленького знака и screenshot/preview.

Правила для всех агентов:

1. Один заметный анимированный маскот на экран, без повторения в каждой карточке.
2. Hero/empty state — 120 dp; небольшая подсказка — 56 dp. В header используйте
   маленькую **статичную** версию. Не растягивайте компонент непропорционально.
3. Happy — приветствие и начало; Calm — пустое состояние/пауза; Focused — работа;
   Celebrating — подтверждённый прогресс; Sleepy — визуальный отдых. Эмоция не
   создаёт и не заменяет health/AI данные.
4. Не копируйте drawing/animation в feature. Импортируйте LifetyMascot.
5. Не делайте маскота препятствием для формы или долгой анимацией перед действием.

## Движение и скорость

Единые spec — `core/ui/LifetyMotion.kt`: Quick 120 ms, Standard 180 ms,
Emphasis 240 ms. Не увеличивайте задержки бизнес-действий ради анимации.

- Root sections и вкладки Плана: fade 120/180 ms, без длинного бокового проезда.
- Строки списков: stable keys/contentType и animateItem для вставки/удаления/перестановки.
- Раскрытие дополнительных настроек: fade + expand/shrink от верхнего края, до 180 ms.
- Заполнение progress bars: 240 ms, только визуальная доля; денежные значения остаются Long.
- Формы: стандартные M3 sheet transitions. Сначала успешная запись, затем закрытие;
  редактор не исчезает до завершения exit animation и не разрешает повторную запись.
- Системный Animator duration scale учитывается Compose. Нет искусственных задержек,
  spring-анимаций каждого контейнера, постоянного glow всего интерфейса и обязательных intro.
- LifetyMascot читает анимацию в graphicsLayer: движение не пересобирает Compose-дерево
  и не перерисовывает Canvas на каждом кадре. Статичная версия остаётся в header.
- Счётчики/сводки мемоизированы по данным, SQLite операции — на IO. Списки lazy.
- У финансового редактора и ручного Health сохраняются поля при configuration change.
  Ключ AI всегда только в process memory, не в saved state.

## iOS-порт — 26 октября 2026

На iOS нижняя панель — нативный UIKit UITabBar с SF Symbols, системной формой
и материалом. Height включает нижнюю safe area; native accessibility включена,
касания передаются без задержки кооперативного распознавания Compose.
UITabBar имеет прозрачный фон и `placedAsOverlay = true`: Compose не вырезает
прямоугольник под native view. Панель размещается поверх полного содержимого
экрана, вне bottomBar-слота Scaffold. `LocalBottomNavigationInset` отодвигает
FAB, ввод чата и последние элементы списка, сохраняя прокрутку под стеклом.
Маршруты остаются общими, календарь — внутри Плана. Android сохраняет Material 3.
Основные формы и экраны остаются Compose; брендовая тёмная тема и зелёный акцент
сохраняются. Системные разрешения Apple Health — стандартный HealthKit sheet,
автоматического запроса доступа при запуске нет. Xcode host поддерживает iPhone
и iPad, системное масштабирование и ориентации.
Проверка панели на iPhone и iPad — [IOS_NAVIGATION_CHECK.md](IOS_NAVIGATION_CHECK.md).

## Планировщик сроков

Раздел «День» сохраняет общий M3-стиль. День выбирается отдельной строкой над
фильтрами, «Все даты» сохраняет доступ к прежнему списку. Сроки на дату,
расписание и просрочка разделены заголовками; одинаковое дело не повторяется
в нескольких группах одного дня. В редакторе дедлайн — первое поле после
названия с быстрыми датами и отдельным временем; скрывающих его switches нет.
Ошибка порядка дат для активного дела с будущим сроком показана непосредственно
под дедлайном, сохранение недоступно до исправления. Просроченное дело можно
перепланировать с прежним сроком. Нативная iOS-панель и общая навигация сохранены.

## Люди

План имеет три внутренние вкладки: «День / Календарь / Люди»; пять основных
разделов сохраняются. Люди используют стандартные M3 Card, текстовый поиск,
FAB и ModalBottomSheet. Инициалы вычисляются из имени, без случайных аватаров.
Редактор содержит имя, строку дня рождения и три списка заметок. Каждый пункт
редактируется отдельно; рядом удаление, в конце списка — «Добавить…». Дата
открывается касанием строки: iOS использует нативные колёсики UIPickerView с
вариантом «Без года», Android — M3 DatePicker с необязательным годом. В месяце ♥ означает день рождения,
• — задачи; подписи и accessibility сохраняют смысл без зависимости от цвета.

## Компактная главная и цели

Главная: дата и «Сегодня», две компактные карточки дел/сроков, горизонтальная
лента целей, короткие строки плана, пара карточек финансов/здоровья. Основные
карточки занимают половину строки; цель имеет ограниченную ширину и прокручивается
по горизонтали. На широком экране контент ограничен 720 dp и центрирован.
Нет дублирующей кнопки «Спросить Lifety». Тема, маскот в app bar и native tab bar
сохранены. Финансы не складывают валюты; у здоровья сохраняется дата замера.
Цель показывает реальные связанные шаги только при наличии импортированной связи.

Обмен ChatGPT открывается из настроек агента как отдельное представление ассистента.
Настроечный sheet закрывается до открытия обмена; системные окна не накладываются
на Compose sheet. До применения — конкретный preview изменений,
затем одно явное действие. Системные share/file pickers используются на iOS/Android.

## Темы Neovim / иконки

Выбор темы применяется сразу и сохраняется локально. Цвет маскота берётся из
`MaterialTheme.colorScheme.primary`, нативный UITabBar обновляет tint при смене.
Не копируйте зелёный акцент в feature; пользовательские цвета категорий сохраняются.
Смена темы не меняет значок сама: явная кнопка применяет соответствующий alternate
icon (iOS) / launcher alias (Android). Ошибка ОС не меняет выбранную тему.
Палитры адаптированы под контраст текста 4.5:1; размеры и типографика общие.
Светлые и тёмные варианты сгруппированы в настройках. На iOS стиль системных
значков, UITabBar и колёсиков даты соответствует теме. Тема сохраняется через
прежний ключ; её смена не меняет иконку автоматически. У светлых вариантов свои
alternate icons. Системная тема устройства не подменяет явный выбор пользователя.

## Ассистент для ручного обмена

Основной экран: компактный header с маскотом 40 dp, подготовка initial/update,
сохранённый запрос/ожидание ответа, прямой импорт с предпросмотром, текущий план.
Нет неактивного поля чата и требования API-ключа. API остаётся в дополнительных
настройках с отдельным возвратом к ручному обмену. Нативные Share/Files вызываются
из основного экрана, за пределами Compose ModalBottomSheet.
Сон выключен по умолчанию, сводка явно описана и доступна до копирования.
Изменения данных или пожеланий блокируют передачу старого запроса; вставка ответа
сразу открывает предпросмотр, отдельное подтверждение применяется к расписанию.

## Прокрутка модальных панелей на iOS

Все десять Compose-панелей используют `core/ui/LifetyBottomSheet.kt`.
На iOS содержимое не передаёт жесты прокрутки перетаскиванию всей панели;
отключён rubber-band overscroll внутри модального окна, инерция сохранена.
Закрыть окно можно кнопкой формы или свайпом вниз
по самому маркеру (от 48 dp). Переход закрытия учитывает SheetState и запрет
закрытия во время сохранения. На Android остаются стандартные жесты Material 3.
Новые панели подключают общий компонент, а не прямой `ModalBottomSheet`.

## Защита разделов и подробное расписание

Настройки содержат вход «Код-пароль на разделы» перед темами. Выбор разделов,
ввод/повтор шести цифр и сохранение выполняются явно. Цифровая клавиатура общая,
поддерживает темы и не сохраняет цифры в saved state. Защищённый экран подменяется
экраном ввода; главная и ассистент также закрыты, когда выводят закрытые данные.
Уход в фон сбрасывает открытую сессию и закрывает настроечные панели.
Это UI-блокировка; точные границы — [SECTION_LOCKS.md](SECTION_LOCKS.md).

План → День: «По времени / Списком», часы свободных окон, карточки с началом,
концом, длительностью и дедлайном. Пересечения выделяются текстом, не только
цветом. Свободные окна создают задачу с выбранным началом; прошедшее время сегодня
не предлагается. Неизвестные длительности явно обозначены. Детали и хранение —
[TIME_PLANNING.md](TIME_PLANNING.md).

В ассистенте bottom-navigation inset добавляется в contentPadding списка,
а не во внешний контейнер: карточки проходят под нативным стеклом до конца экрана.
API composer размещён поверх списка выше панели; у него нет непрозрачной полосы
на всю ширину под UITabBar. Отправка/импорт и бизнес-контракты не менялись.


## Настраиваемые показатели и панель

Здоровье → «Мои показатели»: кнопки добавления и импорта, компактные карточки
с последней записью, архив. Редактор и история используют общий LifetyBottomSheet,
общие темы и нативное поле даты. Видимые точки графика соответствуют реальным
датам; пропуски не заменяются нулями. Источник и единицы подписаны текстом.

Настройки → «Нижняя панель»: явное сохранение, 1–5 пунктов, перемещение вверх/вниз,
добавление из всех семи разделов, возврат стандартного порядка. Все разделы также
доступны из верхней панели. UITabBar остаётся нативным прозрачным overlay;
иконки привязаны к route, порядок не влияет на назначение кнопки.

Редактор запроса расположен в основном экране ручного обмена. Выбор категорий
явный: задачи, цели, финансы, люди, сон, шаги, каждый свой показатель. Без задач
скрыты кнопки импорта расписания; вопрос работает как обычное обсуждение.


## Обзор и ввод — обновление 2026-10-30

Здоровье: две компактные карточки встроенных показателей с последней известной
датой, список своих показателей, один пункт источника с названием платформы.
Основное действие «Запись» отделено от создания определения показателя.
Периоды, графики и история показаны в деталях. Короткие формы занимают высоту
содержимого; весь сценарий здоровья использует один sheet и меняет его содержимое.
Системное чтение шести категорий имеет единый предпросмотр и отдельное сохранение.

В задачах краткие строки показывают заданные даты, настройки раскрываются.
В контексте ассистента «Данные» отделены от «Разговора»; сохранение закреплено,
строка переключателя имеет полный click target высотой не меньше 48 dp.
Редактор панели использует компактные строки; кнопки имеют уникальные описания.
Палитра, типографика и shape tokens прежние. Обоснование: [UX_REDESIGN.md](UX_REDESIGN.md).


## iOS native controls — 30 октября 2026

На iOS корневая верхняя панель теперь UINavigationBar с центральным заголовком,
SF Symbols и системными кнопками. Основная навигация остаётся прозрачным UITabBar.
Внутренние вкладки Плана, фильтры задач, периоды здоровья/финансов и вкладки
контекста ассистента используют общий LifetySegmentedControl: UIKit на iOS,
Material на Android. Не рисовать дополнительный прямоугольный фон под стеклом.

LifetyDateField на iOS показывает компактный UIDatePicker; в редакторе задач дата
и время встроены в группу полей, без вложенного Compose date/time dialog.
«Указать» создаёт значение только в черновике; «Убрать» возвращает null.
Окончание задачи выбирается системным time picker. Для нативного календаря
используется местный часовой пояс и понедельник в начале недели. Нельзя просто
передать UTC midnight в local picker: дата сместится на устройствах западнее UTC.
Формат native времени задаёт iOS, включая 12/24 часа.

Типографика iOS: крупные заголовки 34/28/22, основной текст 17/15, подписи 13 sp,
без Android tracking. Палитры общие. State switches — UISwitch реального размера
intrinsicContentSize, без фиксированных устаревших размеров. Повторная передача
уже выбранного значения не обрывает системную анимацию switch/segmented control.

UIKit controls внутри прокручиваемой формы не используют placedAsOverlay:
иначе они рисуются поверх footer и вне видимой части списка. Прокрутка получает
приоритет через cooperative interaction; fixed navigation bars остаются
NonCooperative. Редактор задач имеет компактную строку «Отмена / Задача / Удалить».
Остальные поверхности и большая часть форм остаются общими Compose-компонентами.
Проверки и ограничения — [IOS_NATIVE_UI.md](IOS_NATIVE_UI.md).


## iOS-формы, дуга и фиксированное расписание — 30 октября

- В iOS-формах используется общий `LifetyTextField`: мягкая заливка и углы 12 dp,
  без outline/нижнего индикатора. Android сохраняет Material OutlinedTextField.
  Редакторы с чувствительным к позиции курсора вводом владеют TextFieldValue
  локально, без обратного присваивания устаревшей строки из StateFlow.
- Цвет native view совпадает с фактической поверхностью `LocalNativeSurfaceColor`;
  UISwitch измеряется после размещения и центрируется в контейнере 80×44 dp.
  Контейнеры и SwiftUI host обновляются при смене палитры.
- Маркер iOS-панели не является кнопкой. Короткий свайп возвращает панель,
  длинный/быстрый закрывает; прокрутка содержимого отделена от движения панели.
- Нижняя панель: обычный UITabBar по умолчанию или опциональная SwiftUI-дуга.
  Центральная капсула 88×50 pt; разделы 66 pt на верхней дуге радиуса 116 pt.
  Используется системный Liquid Glass и SF Symbols. Тап дублирует удержание,
  есть accessibility labels/escape; Reduce Motion отключает spring-анимацию.
- Временная сетка показывает фиксированные занятия и задачи в соседних колонках
  на одной шкале: 72 dp на час. Пересекающиеся блоки одной колонки получают
  отдельные дорожки; конфликт задачи отмечается errorContainer. Записи доступны
  также обычным списком. Сетка сворачивается и не скрывает записи вне своих часов.
- Семь дней недели в редакторе расписания помещаются в одну строку без обрезания.
  Время/разовая дата на iOS выбираются системными controls.
